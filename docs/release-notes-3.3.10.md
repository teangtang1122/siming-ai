# 司命 3.3.10

3.3.10 修复 AI 章节草稿在生成后角色、设定等来源发生变化时无法保存的问题，并补齐 PC 与 Android 的草稿删除入口。AI 生成内容仍与正式章节分离；保存或删除都必须由作者明确决定。

## 章节草稿保存恢复

- 生成前继续严格校验角色、世界观和大纲等上下文是否为最新，避免 AI 基于过期来源继续写作。
- 草稿已经生成后，即使角色等来源随后变化，作者仍可审阅并保存该草稿；服务端使用草稿生成时记录的来源信息完成归档，不再把后续来源变化误判为保存失败。
- 草稿保存继续绑定服务端持有的作品、章节和来源记录，客户端不能通过修改请求伪造草稿归属或绕过写入边界。
- 已保存章节的 AI 修订仍沿用版本冲突保护，不会静默覆盖其他页面或设备刚保存的新正文。

## 删除草稿按钮

- PC 正文编辑页的未保存草稿区域新增“删除草稿”按钮，并在删除前明确确认影响范围。
- PC 项目助手的章节草稿卡片同步提供“删除草稿”，无需先切换到正文页。
- Android 章节工作区提供同等的删除入口，并通过 Gateway 或 PC 直连调用同一服务端语义。
- 删除操作可安全重复调用，只移除指定的未保存 AI 草稿并释放占用状态；不会删除或改写任何正式章节。
- 删除修订候选后，编辑器会恢复作者原有的未保存内容；已删除草稿不会进入项目导出包，也不会在重启后重新出现。

## 兼容升级

本版本不新增数据库迁移。既有作品、正式章节和 3.3.9 的对话 checkpoint 数据保持兼容，可直接覆盖安装升级。

## 下载

正式 Release 提供：

- `Siming-Setup.exe`：Windows 10 x64 或更高版本安装包
- `Siming-Setup.sha256`：Windows 安装包 SHA-256
- `Siming.apk`：Android 8.0 或更高版本正式签名安装包
- `Siming-apk-sha256.txt`：Android APK SHA-256

Windows 项目当前尚未配置 Authenticode 证书时，请在安装前同时核对 Release 提供的 SHA-256；Android APK 使用正式发布密钥签名。
