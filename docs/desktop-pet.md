# 司命桌宠

## 当前唯一运行路径（3.5.0）

Windows PyWebView 透明悬浮窗 → `/desktop-pet` → `DesktopPetApp` → `poses/PoseCanvas` → 连续整图网格。
当前版本为 `poses-pickup-20260929`，不再加载 Cubism SDK、MOC 或旧 Live2D 动作。

- 素材契约：`frontend/src/features/desktopPet/poses/manifest.json`。
- 运行素材：`frontend/public/desktop-pet/poses/`，原 12 张 384×576 WebP 保持哈希不变，新增 3 张 1024×1536 透明 PNG，共 6,439,267 字节。所有姿势都在同一个 384×576 逻辑画布中显示；新 PNG 保留原始像素，只在渲染及命中扫描时使用同一等比对齐矩形。
- 单一渲染器：`frontend/src/features/desktopPet/poses/renderer.ts`。
- 业务状态来自共享 operations API/SSE；桌宠不创建任务、不保存草稿、不建档、不自动续写。
- 网页、Gateway 和 Android 不创建 Windows 悬浮窗。共有任务状态继续遵循同一 operations 契约。

## 姿势和交互

| 真实状态 / 行为 | 姿势 |
| --- | --- |
| 待机、等作者、完成、错误 | 抱书站立 |
| 思考、写作；或空闲时右键选“翻翻小书” | 低头读书 |
| 空闲时打盹 | 坐着抱书睡觉 |
| 已确认停靠屏幕左 / 右边缘 | 贴边偷看，右侧镜像完整原画 |
| 指针位移超过拖动阈值，正在拖动 | 被轻轻拎起：抱紧书、双腿悬空、衣袖自然垂下 |

姿势直接切换，不做肢体补间。读书、探头、被拎起的眨眼仅采样两块旋转眼区；衣服、脸、手和书始终来自基准纹理。站姿保留已确认的五帧眨眼，坐姿保持闭眼。呼吸和点头使用一张连续网格，脚底不漂移；没有拆开的手臂或袖子。被拎起使用专门的完整悬垂画，不套用站姿的点头 / 呼吸变形，不持续摇袖子；松手或取消拖动立即恢复当前任务 / 环境姿势，不改变任务状态。轻点不触发被拎起姿势，拖动不弹气泡。2026-09-29 起不再使用固定八秒动作循环：眨眼间隔约 3.1～7.2 秒；偶发点头 / 侧倾后保留 8～16 秒安静间隔。探头包含探出、停留观察、收回一点三个阶段，随机只用于安排小动作时间，不产生逐帧抖动。减少动态效果时仍完全静止。

气泡默认隐藏，轻点角色（键盘 Enter / 空格同效）才显示颜文字文案并点头回应，5 秒后用 180ms 淡出并从 DOM 和原生命中区域移除。再次轻点换一句并重新计算完整显示时间，淡出中点击也可恢复；悬停、拖动、切换姿势和任务状态变化都不会主动显示或延长气泡。任务和断线说明也采用同一点击展示规则。拖动保留原生边界限制，双击回书斋。右键菜单的“小动作”可立即体验读书、坐睡、左右探头；有真实任务或连接错误时禁用手动覆盖。新任务、点击和拖动结束休息姿势。睡眠可由鼠标唤醒；探头不因悬停而消失。

空闲十分钟后仍按 50% 打盹、25% 左探头、25% 右探头选择。拖到边缘放下也触发探头。原生窗口始终限制在当前显示器工作区，只有完整原画向侧边移出视口；不会单独隐藏身体，也不会在原生停靠失败时假装探头。

气泡显示时位于角色内侧，窄工作区可置顶。空闲、读书、打盹和探头的文案保留纸笺外观，正文为 12px；任务、断线或加载状态才显示标题，任务进度继续保留。操作提示移到右键菜单；探头使用短句气泡。各姿势共用头部比例和逻辑坐标，切换及气泡显隐不会自动放大。默认窗体 272×240（340×300 × 0.8），仍可调整大小、透明度、置顶、静音。菜单内容过多时内部滚动，不越出窗口。

贴边探头时按露出的头发轮廓和气泡范围收窄原生窗口，鼠标输入层同步收窄；角色和气泡维持进入探头前的大小，气泡靠近脑袋并朝向屏幕内部。实际窗口尺寸随缩放设置、显示器 DPI 和气泡可见状态计算。唤醒、拖动或修改大小时先恢复完整窗口；重复探头不会累积缩小。原生层按 CSS 视口与窗口的比例换算尺寸，保持左 / 右工作区边缘锚定。

所有姿势都按素材 alpha 轮廓生成原生命中区域，附加约 6px 的抓取 / 小动作余量，以及气泡和菜单的操作范围。仅单 alpha 的输入层应用 Region；WebView 显示窗口不裁剪，通过 `WS_EX_LAYERED | WS_EX_TRANSPARENT` 将指针交给下层，句柄重建时重新设置。这样空白处点击交给下方应用，角色和气泡由输入层接收；不使用整窗透明输入矩形作为已就绪状态。显示窗口不能套用轮廓 Region，否则 WebView2 的原生合成会在透明边缘显示黑块。此处的分层窗口穿透依据 [Windows 分层窗口说明](https://learn.microsoft.com/en-us/windows/win32/winmsg/window-features#layered-windows)。轮廓仅在姿势或布局变化时计算，桥接更新去重、串行并保留最新布局；不会每帧回读画布或每帧重建 Windows 区域。拖动期间保留原生鼠标捕获，避免越过轮廓空隙后收不到松手事件。同步失败显示诊断状态和菜单提示，不静默退回旧输入路径。

动画正常 30 fps、睡眠 20 fps；页面隐藏时停止 RAF。减少动态效果偏好下不播放眨眼 / 点头。声音仍是本地 WebAudio 短提示，默认静音。

右键大小滑块按 1% 步进实时预览；原生请求间隔至少 16ms，最多一个进行中，只保留最新待处理值，不积压中间尺寸。滑块使用固定屏幕坐标和起始轨道宽度计算本次手势，通过页面级指针监听持续接收 WinForms 转发的拖动；不能依赖原生 `SetBounds` 后会丢失的 DOM 指针捕获。调节期间固定菜单宽高，按当前工作区的最大缩放空间选择固定的左右 / 上下锚点，原生窗口与菜单使用同一锚点，避免到屏幕边缘后改向移动。松手、取消、失焦或控件卸载时结束手势并恢复菜单布局，键盘调节仍可用；一次手势只保存最终值。

设置保存串行并保留更新的本地草稿，失败回退并提示。自身预览不广播回原页面，避免迟到回执把滑块拉回旧值；主窗口保存的设置仍广播同步。窗口与 ResizeObserver 的通知合并到下一绘制帧，仅尺寸确实变化时重设画布，并在同一帧画回角色，不清空纹理或重建渲染器。主设置页仍采用明确点击“保存桌宠设置”的草稿语义。

## 原画与旧工程

本机的站立 / 读书 / 探头 / 打盹制作记录保存在 `output/siming-material-variants-20260926/`；该目录是未提交的历史审核小样，不是第二个正式加载入口。运行贴图使用其中已审核的精确哈希，探头手势保留 v4 局部修正。被拎起的内置 imagegen 提示词和三张未改写 PNG 本地存档于 `output/siming-pickup-20260929/`；正式资源引用只来自已提交的 `frontend/public/desktop-pet/poses/`，克隆仓库不需要这些本机存档即可构建。


独立预览加 `--check-compact` 可通过预览自身的 DOM 和正式原生桥执行左右各两次收缩 / 恢复检查，不操作系统鼠标键盘。检查真实 WinForms 窗口与输入层边界、气泡可见范围、原尺寸恢复，并用只读 `WindowFromPoint` 和 `GetAncestor` 验证空白处不命中两个桌宠 HWND（包括 WebView 子窗口）；同时验证角色像素落在输入区域内且实际命中输入层。报告写入 `output/siming-desktop-pose-preview-20260927/native-compact-qa.json`，成功后保留右侧探头供人工观察。加 `--check-composition` 会短暂显示与预览同尺寸、不抢焦点的自有纯色测试底板，只截取底板覆盖的预览矩形，检查站立及左右探头原生合成结果的透明处没有黑块；截图为同目录的 `native-composition-*.png`，测试底板随后关闭。此项不能用浏览器截图或 DOM 的透明背景样式代替。

独立预览还验证气泡初始隐藏、点击显示、重复点击换句并续时、超时移除以及原生输入区域随之缩小；合成检查分别保留无气泡、显示中和消失后的截图。前端单测覆盖五秒寿命、淡出、淡出中再次点击、取消 / 拖动不弹出、任务说明同样按点击展示，以及气泡移除后角色和菜单仍可命中。后端单测覆盖 100% / 150% / 200% 尺寸比例、输入区域资源释放、显示窗口不裁剪、透明窗口样式保留 / 句柄重建和负坐标显示器。

独立预览通过自身的指针事件额外验证拖动超过阈值后切入 `picked_up`、采集三种实际眨眼帧、检查原生命中与透明合成，并验证松手 / 取消恢复站姿且不误弹气泡。截图和检查结果仍在同一个独立预览目录。

`--check-resize` 在屏幕左上、中央、右下三个位置，分别从 70%、100%、135% 开始，共九组；使用正式输入转发器向预览 WebView2 发送按下、48 次往返移动和松手，以固定屏幕轨迹实际拖动滑块，不直接改数值冒充鼠标交互。记录指针捕获、数值单调性、原生窗口、轨道位置、绘制间隔和保存次数到 `native-resize-drag-qa.json` 及各组的独立报告，要求能拖到 135% 再拖回 70%，没有倒退，最多保存一次；随后恢复预览原设置。该检查不移动 / 捕获系统鼠标或发送系统键盘事件，也不修改安装版设置。

`npm run build` 和 Windows 打包都强制 `pet:check`：精确校验 15 张素材的 SHA-256、帧数、眼区、原图尺寸 / RGBA、贴边锚点，并拒绝把旧渲染器放回发布资源目录。缺失 / 损坏素材明确失败，没有静默回退。

独立预览调用同一正式 launcher、后端、桌宠页面和原生输入桥，只隐藏预览主窗口，使用 `output/siming-desktop-pose-preview-20260927/home/` 独立数据目录。不会覆盖、重启或连接已安装司命的数据。右键“回到司命书斋”打开的是预览实例；关闭该预览主窗口可退出。源码更新不代表已安装的 `D:\Siming\Siming.exe` 已更新。
