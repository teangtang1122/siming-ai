# 司命 3.3.4

3.3.4 是章节草稿可靠性修复版本，解决同一章节生成请求并发、重试或迟到完成时，草稿看似可编辑但两种保存方式都失败，并继续阻塞后续写作的问题。

## 章节草稿并发与恢复

- 每部作品现在只允许一个作者可见的待保存章节草稿；先完成并成功落库的草稿保留编辑席位，迟到结果不能再把它标记为已替代。
- 长耗时章节生成结束后会重新读取正式章节和待保存草稿状态，不再沿用模型请求开始前的旧事务视图。
- 数据库新增部分唯一索引作为最终并发保护；两个生成结果同时完成时，只有一个能进入待保存状态。
- 如果目标大纲在生成期间已经保存为正式章节，迟到结果会被安全丢弃，不覆盖正文，也不创建注定无法保存的草稿。
- 升级会保留每部作品最新的有效待保存草稿，并把重复草稿或已对应正式正文的旧草稿标记为 `superseded`，解除后续写作阻塞。

## PC 与 Android 一致性

- 聊天中的草稿保存失败会显示明确错误，不再表现为按钮无响应；正文编辑器也会持续显示保存失败状态与原因。
- 保存失败后，PC 和 Android 都会重新读取权威待保存草稿状态；服务端已释放的迟到草稿不会继续留在界面中诱导重复保存。
- Android Gateway 路径复用同一后端约束；Android 独立模式新增确定性的待保存草稿阻塞和旧草稿释放状态，不再只依赖模型提示词避免续写。
- 草稿仍只有在作者明确选择“仅保存”或“保存并建档”后才会成为正式章节；建档完成前不会自动续写下一章。

## 下载

正式 Release 提供：

- `Siming-Setup.exe`：Windows 10 x64 或更高版本安装包
- `Siming-Setup.sha256`：Windows 安装包 SHA-256
- `Siming.apk`：Android 8.0 或更高版本正式签名安装包
- `Siming-apk-sha256.txt`：Android APK SHA-256

Windows 项目当前尚未配置 Authenticode 证书，安装前请同时核对 Release 提供的 SHA-256；Android APK 使用正式发布密钥签名。
