# 司命 3.3.3

3.3.3 增加了可验证、可跨端迁移的“司命项目包”，并把项目数据迁移与普通小说文档导入彻底分开。本版本同时正式收录 3.3.2 发布后完成的 Android 助手恢复、实时流式输出、小说导入和立项一致性修复。

## 司命项目包

- PC 与 Android 均支持 `.siming-project` 项目包，协议固定为 `siming-project-package` v1，并提供“完整项目”和“仅结构”两个档位。
- 完整项目包保存作品设置、立项结果与版本、大纲、角色关系、世界观关系、正式章节、快照、摘要、独立未保存草稿、作者已应用的叙事治理数据和原始立项素材。
- 仅结构包保留写作设置、当前立项简报、大纲、角色和世界观关系，严格排除正文、草稿、快照、摘要、素材、历史版本及正文证据。
- 自动任务、助手对话/运行/记忆、RAG、运行日志、缓存、Skill、Prompt Pack、MCP、外部 Agent 权限和模型执行配置不会进入任何档位，也不会因导入而启动。
- 项目包导入始终创建新作品，不覆盖或合并现有作品；相同幂等请求可安全重试，不同请求键可有意导入多份。
- 导入会先校验 manifest、条目白名单、Schema、记录数、大小和 SHA-256，再开始数据库事务；同时拒绝目录穿越、重复路径、符号链接、加密 ZIP、压缩炸弹和超限素材。
- 素材恢复到新作品目录并重建确定性索引；缺失素材会让完整导出明确失败，不再写入失效的旧路径。

## 外部小说导入与常规导出

- “导入司命项目包”和“导入外部小说”成为两个独立入口，不再根据普通 ZIP 或文档内容猜测数据类型。
- 外部小说支持 TXT、Markdown（`.md`）和 DOCX，只创建新作品与正式章节，不推断角色、世界观、任务或运行态。
- Markdown 标题可作为章节边界，正文标记会原样保留；TXT 的多编码识别、DOCX 安全解析、20 MiB 限制和最多 2,000 章的边界在 PC 与 Android 保持一致。
- Gateway 在线导入使用一次上传和一个数据库事务；离线 Android 导入在本地事务完成后再进入同步队列。
- 导出页继续提供 TXT、DOCX 和 PDF，并把完整/结构项目包放在单独区域，避免把阅读文档与可恢复项目包混用。

## Android 与助手可靠性

- Android 直连模型改为消费 Chat Completions / Responses API 的真实 SSE 增量，正文、可见推理和工具参数不再等待整段响应后模拟分片。
- Gateway 助手补齐会话历史、运行 ID、工具日志、显式取消和断流恢复；手机独立会话及工具日志可跨进程重启恢复。
- 思考模型遇到不支持的 `tool_choice` 时按供应商能力省略参数；只有在尚未输出内容且接口明确拒绝时才安全重试。
- AI 生成章节继续只进入独立未保存草稿，作者明确保存后才成为正式章节；迟到请求不能覆盖当前草稿。
- Android 的立项创作约束、正式建档结果、小说导入和项目包同步顺序与 PC 权威契约对齐。

## 数据升级与修复

- 新增项目包导入幂等回执表，防止网络重试产生重复作品或把同一请求键用于不同内容。
- 修复旧数据库缺少 `character_change_logs.chapter_version` 时的启动与项目包导出错误；升级会自动补列并按既有章节版本回填。
- 修复 Windows 桌面内嵌页面无法把常规导出或项目包保存到用户选择位置的问题。
- 项目包提交后只排队确定性的作品镜像和检索索引重建，不创建或执行自动任务。

## 下载

正式 Release 提供：

- `Siming-Setup.exe`：Windows 10 x64 或更高版本安装包
- `Siming-Setup.sha256`：Windows 安装包 SHA-256
- `Siming.apk`：Android 8.0 或更高版本正式签名安装包
- `Siming-apk-sha256.txt`：Android APK SHA-256

Windows 项目当前尚未配置 Authenticode 证书，安装前请同时核对 Release 提供的 SHA-256；Android APK 使用正式发布密钥签名。
