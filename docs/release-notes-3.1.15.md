# 司命 3.1.15

本版本完善了本地 CLI 的 MCP 写入链路，并改进桌面端小说导出体验。

## 修复与改进

- 导出小说时可选择保存目录，EXE 启动场景下也会使用用户选择的位置。
- API 模型提示词不再混入仅供 CLI 使用的写入工具说明，避免模型模板解析失败。
- OpenCode 等本地 CLI 通过司命 MCP 工具写入新书立项数据，并在返回前校验数据库 revision，防止未写入却误报成功。
- MCP 写入工具兼容标准 JSON Patch 的 `op` 字段及数组追加路径 `/字段/-`。
- 修复打包版 EXE 作为 stdio MCP 服务运行时的输入输出连接，并延长外部 CLI 的 MCP 超时时间。
- 增加打包版 MCP 写入冒烟测试。

## 发布资产

- `Siming.exe`：Windows 桌面版。
- `update.json`、`sha256.txt`：自动更新与完整性校验文件。
