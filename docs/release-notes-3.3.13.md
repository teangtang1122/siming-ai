# 司命 3.3.13

3.3.13 是长篇创作、章节建档和跨端一致性的高可用版本。本版来自一部 41 章、157,104 个正文汉字作品的逐章真实生成、建档、导出和回导复验，并合入 3.3.12 之后的远程可靠性更新。

## 未知模型容量兜底

- 未配置容量档案的远程未知模型使用 256,000 tokens 有界兜底，让不了解上下文容量设置的作者仍可开始使用。
- 作者保存并启用的精确 `provider/model` 容量档案始终优先；官方目录、本机运行时和请求中已有的可信容量也优先于兜底。
- 兜底会明确标记为 `unverified`，不会伪装成供应商确认值；PC、Gateway 与 Android 使用同一优先级。

## 未保存草稿可继续修改

- 作者不满意 AI 初稿时，可以直接要求 AI 修改当前未保存草稿，不必先把不满意的正文保存或建档。
- 修订会原位替换同一草稿，不创建第二份草稿，也不会自动保存、建档或续写下一章。
- 草稿生成期间若作者又手工修改、保存或丢弃，迟到的模型结果会因来源版本冲突被拒绝，避免覆盖作者的新内容。
- API、工作区助手、本机 CLI/MCP 与 Android 使用相同的草稿 ID、归属、状态和冲突契约。

## 重复建档与章节重建档

- 相同章节正文版本的重复点击、HTTP 重试或 CLI 重试会复用已有建档任务，不会重复应用人物、关系、世界资料和场景候选。
- 语义修改正式章节时，当前章及后续受影响章节的旧派生资料按正文来源回滚并标记为需要重新建档；显式 `style_only` 润色保留原建档结果。
- 章节大纲以原节点身份原位替换，标题或摘要变化不会造成错位；所属卷和排序保持不变。
- 新建档大纲成功后才清理旧 section 与历史建档投影，失败时不会出现“旧大纲已删但新大纲未创建”的半完成状态。
- `full` 项目包导入会修正旧包中的大纲所有权和规划残留；历史失活世界资料保留用于审计，但不会作为当前设定进入 RAG 或后续创作。

## 长篇创作与跨端可靠性

- 建档候选采用结构化身份、字段所有权和来源证据进行验证，减少同章重试产生的重复或错误词条。
- 章节保存、回滚、重新建档、候选应用和任务取消收敛到同一权威业务路径。
- PC、API、本机 CLI/MCP 和 Android 对目标 ID、参数校验、分页、任务状态及持久化结果保持一致；手机端仍可在移动端架构内独立运行。
- 项目助手取消固定工具轮次上限，以类别选择、授权交集、事务、超时和取消作为执行边界。

## 数据升级

安装后首次启动会按现有流程备份并升级数据库。`300a35_relationship_integrity` 修复关系完整性，`300a36_outline_projection_identity` 为已有章节大纲补齐稳定来源身份。迁移不会删除正文或正式章节。

## 验证

- 真实作品：41 个正式章节、157,104 个正文汉字、41/41 完成建档。
- 完整项目包经正式 exporter 导出、全新数据库导入、RAG 重建、再次导出和逐章正文哈希核对。
- 未保存草稿完成两轮真实 AI 修订及并发手工编辑保护复验，始终保持同一草稿且没有生成正式章节。
- Windows、后端、前端与 Android 发布门禁在标签构建中再次执行；只有全部通过后才发布附件。

## 下载

正式 Release 提供：

- `Siming-Setup.exe`：Windows 10 x64 或更高版本安装包
- `Siming-Setup.sha256`：Windows 安装包 SHA-256
- `Siming.apk`：Android 8.0 或更高版本正式签名安装包
- `Siming-apk-sha256.txt`：Android APK SHA-256

Windows 项目当前尚未配置 Authenticode 证书时，请在安装前同时核对 Release 提供的 SHA-256；Android APK 使用正式发布密钥签名。
