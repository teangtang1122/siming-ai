# 司命 3.4.5

3.4.5 将手机写作、资料管理和导出流程改为独立运行。配置手机 API 后即可立项、写章和建档；保存过 Gateway 地址或电脑暂时离线，都不会把手机操作改为 PC 代办。本次同时发布 Android、Windows PC 安装包和 Gateway 镜像。

## 手机独立操作

- 作品、正文、大纲、角色、世界观、伏笔和治理资料在手机事务中保存，维护版本、关联、检查点和建档状态。
- 章节排序、历史查看、差异比较与版本恢复可在手机完成。恢复生成新版本，回退受影响的建档来源，并要求重新建档；作者后续手工修改得到保留。
- 角色关系、AI 配置、角色版本，以及世界观版本和时间线从实际本机资料读取或更新，不需要 PC 在线。
- 新章和修订候选继续保持未保存草稿，作者确认后才写入正式正文。导入或从 PC 带来的章节草稿也可以在手机修改、保存和丢弃。
- 旧 PC 立项草稿提供“转为手机独立立项”，从手机已保存的创意、阶段资料和会话记录继续编辑、确认及建立作品；后续 AI 对话使用手机 API。
- TXT、Markdown、DOCX 和司命项目包在手机导入；TXT、Word（DOCX）及 PDF 在手机导出。PDF 使用 Android 字体和分页，具体版式可能与 PC 不同。
- 已同步或上传中断的作品也能直接从手机移除，清理本机原包及同步队列；其他设备副本保留，后续不会自动重新下载。立项草稿同样可以从手机移除。
- 未配置 API 时仍可使用“稍后配置”进入本机作品库，完成导入、手动编辑、历史操作和导出。

## 同步与升级

手机独立使用不要求 PC 运行。Gateway 作为可选的跨设备同步和远程模型入口保留；作者显式选择 PC 模型时，对应远程任务仍需要该主机在线。

**需要同步本版的章节恢复、排序、关系替换、草稿状态和项目包修改时，请将 PC/Gateway 一并升级到 3.4.5。** 旧 Gateway 无法接收新增命令时，手机结果和待同步记录会保留，并显示错误。

- PC/Gateway 接收手机操作后调用现有领域服务，将正文和衍生历史、治理状态及删除标记放在同一事务中确认。
- 同步按操作顺序执行，回执丢失后使用同一操作 ID 重试，防止重复恢复、重复建档或生成重复历史；旧回执不会清除作者后来的修改。
- 导入回执记录固定的初始同步版本。手机导入后离线修改可以在首次同步时正确接续，PC 期间发生的真实修改冲突也会保留。
- 本机数据库升级保留正文、历史、立项资料和待同步队列，将旧版手机 Key 的立项草稿迁为设备执行。角色与世界观历史只展示实际保存或导入的版本，不补造缺失记录。

## 测试范围

- 本地通过 347 项 Android JVM 测试、20 项 Android API 35 设备回归、1 项全新应用数据下的“稍后配置”验收，以及 101 项后端相关回归。
- Android Debug、Android Test APK 构建与 Lint、架构及导入边界检查、28 项移动能力契约检查通过。两端共用输入校验、章节差异及治理状态样例验证关键行为。
- 设备回归覆盖无 Gateway、已配置但不可达的 Gateway、旧草稿处理、建档取消与重试、历史恢复、删除、旧数据库升级，以及网络中断后的同步与冲突保护。
- 使用合成中文内容验证 DOCX 正文与转义，并在设备导出 150 段、4 页 PDF，检查分页、全部正文提取及渲染。未使用真实用户作品作为公开测试数据。
- 正式安装包由版本标签流水线重新构建，执行前后端和 Android 检查、Windows 安装及启动冒烟、签名/版本/校验值验证和发布后下载核验。

**既有 AI 实际运行问题分析与测试主要基于 DeepSeek API 的 `deepseek-flash`。本次使用合成资料、模拟模型及网络故障回归，未进行真实 DeepSeek 端到端联调，也未实测 CLI。使用其他模型或 CLI 可能存在未知 bug，尚未完成同等范围的实机验证。**

独立模式不内置桌面本地模型、CLI、MCP 或训练运行时。完整功能范围与平台差异见 [手机独立操作验收](https://github.com/teangtang1122/siming-ai/blob/v3.4.5/docs/testing/mobile-independent-authoring.md)。

## 下载

- `Siming-Setup.exe`：Windows 10 x64 或更高版本安装包。
- `Siming-Setup.sha256`：Windows 安装包校验值。
- `Siming.apk`：Android 8.0 或更高版本正式签名安装包，可升级已有正式版。
- `Siming-apk-sha256.txt`：Android 安装包校验值。
- Gateway：`ghcr.io/teangtang1122/siming-ai-gateway:3.4.5`，支持 amd64 和 arm64。
