# 司命 3.3.6

3.3.6 是前端编辑状态稳定性修复版本，重点解决已有角色时点击新增会被列表刷新选回旧角色，以及慢网络或连续切换时旧请求覆盖当前编辑对象的问题。

## 角色新增与保存

- 角色页现在明确区分首次加载、空列表、新建角色和查看正式角色，不再用同一个空 ID 表示多种状态。
- 已有任意数量角色时，点击“＋”会稳定保留空白新建表单；列表刷新、旧角色详情、版本记录或 AI 配置迟到返回都不能选回旧角色。
- 新建状态始终调用角色创建接口，正式角色编辑始终调用对应 ID 的更新接口。
- 创建请求期间继续输入时，会先绑定服务端返回的新角色 ID，同时保留较新的本地内容；下一次保存更新该角色，不会重复创建。

## 慢网络下最后一次操作生效

- 新书立项资料编辑器按 `session + stage` 校验读取、保存和版本历史；返回、关闭、切换会话或继续输入都会使旧响应失去界面写回权。
- 系统助手与项目助手的历史对话按 conversation ID 隔离。点击“新对话”后，旧历史响应不会恢复旧消息、运行卡片或日志。
- 提示词包、作品建档、拆书报告、技能版本和 Context Manifest 详情统一遵循“最后选择的目标拥有写回权”，避免标题、列表高亮和详情内容来自不同对象。
- 请求取消仍用于节省资源，但界面正确性不依赖取消时机；即使响应按相反顺序完成，也只提交当前目标的数据。

## 契约与兼容性

- 后端 API、数据库结构、Gateway 同步协议和 Android 业务契约没有变化。
- Windows、Android 与 Gateway 版本统一为 3.3.6；Android `versionCode` 为 `30306`。
- 新增可控延迟 Promise 回归测试，覆盖角色新建/保存、立项资料、对话历史及各详情面板的乱序响应。

## 下载

正式 Release 提供：

- `Siming-Setup.exe`：Windows 10 x64 或更高版本安装包
- `Siming-Setup.sha256`：Windows 安装包 SHA-256
- `Siming.apk`：Android 8.0 或更高版本正式签名安装包
- `Siming-apk-sha256.txt`：Android APK SHA-256

Windows 项目当前尚未配置 Authenticode 证书，安装前请同时核对 Release 提供的 SHA-256；Android APK 使用正式发布密钥签名。
