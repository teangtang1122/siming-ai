# 司命 3.4.7

3.4.7 修复立项、章节生成、建档和大纲保存中的多项问题，并同步更新 PC、Android 和 Gateway 的共享业务契约。

## 立项与模型工具

- 精简立项提示词，明确创作约束、创意方向、角色与世界观的归属；创意方向默认生成一个方案。
- 修复最终审阅只回复完成却没有保存阶段资料的问题，以实际写入结果显示状态。
- 按小型能力类别开放工具，每步最多选择两个类别；固定任务直接使用该任务授权的工具。
- 改善本地模型的 Token 估算、上下文读取和工具结果容量检查，减少过度预留导致的误拦截。
- 补充本地模型运行设置、上下文追踪和检查点恢复信息。

## 正文、建档与去 AI 味

- 移除未经作者指定的 3000 字硬性退回要求。字数目标作为提示，完整正文先形成独立草稿，由作者决定保存和建档。
- 修复建档候选结构校验、工具授权和恢复流程，保留已完成内容与候选项，失败时可从检查点继续。
- 去 AI 味改为局部修改，保留未修改的原文，减少整章重写造成的内容删减和等待时间；保留校验与作者确认。
- 对齐手机与 PC 的字数提示、建档、上下文读取及取消、重试契约。

## 大纲生成与保存

- 已有大纲用完后，下一章规划默认生成一个章节草稿，作者确认后写入正式大纲。
- 改善本地模型大纲流式生成与超时处理，缩小返回 Agent 的结果，保留作者可查看的完整草稿。
- 区分正式节点与 AI 草稿的保存入口，草稿保存后显示“草稿已保存 · 待确认”，编辑后显示未保存修改。
- 修复正式节点保存误删隐藏卷纲范围等字段、造成草稿确认冲突的问题。
- 防止后台刷新或迟到请求覆盖正在编辑的草稿；手机同步显示草稿保存与确认状态。

## 验证与发布

- 发布前执行前端测试、架构与 API 类型检查，后端质量与发布契约检查，以及 Android 单元测试和 Lint。
- 本轮已在安装后的 PC 客户端验证草稿保存、重新打开、状态一致和原有正文保留，并记录本地模型章节与下一章大纲的实测结果。
- 正式安装包由版本标签流水线重新构建，执行 Windows 安装启动冒烟、Android 签名与版本检查及发布后下载核验。
- Gateway 镜像执行 amd64、arm64 构建与启动检查。

## 下载

- `Siming-Setup.exe`：Windows 10 x64 或更高版本安装包。
- `Siming-Setup.sha256`：Windows 安装包校验值。
- `Siming.apk`：Android 8.0 或更高版本正式签名安装包，可升级已有正式版。
- `Siming-apk-sha256.txt`：Android 安装包校验值。
- Gateway：`ghcr.io/teangtang1122/siming-ai-gateway:3.4.7`，支持 amd64 和 arm64。
