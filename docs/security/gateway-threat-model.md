# Gateway 与 Android 威胁模型

## 范围与信任边界

Gateway 是单用户、自托管同步中枢，不是多租户 SaaS。所有者负责部署设备、网络、域名、TLS、备份和云端模型账号。司命官方不接收小说正文，也无法替用户恢复自托管数据库或管理口令。

受保护资产包括作品正文、结构化档案、云端 API Key、设备访问/刷新令牌、Gateway Ed25519 签名私钥、数据库备份和 Android 本地副本。

## 主要威胁与控制

| 威胁 | 已有控制 | 剩余风险与建议 |
| --- | --- | --- |
| 远程抢占首个所有者 | 配置管理口令后，远程配对创建与批准均需所有者会话；loopback 桌面先建立本机所有者 | 管理口令仍需足够随机，并由部署者安全保存 |
| 二维码截屏或重放 | Ed25519 签名、Gateway 指纹、协议版本、10 分钟过期、一次性 secret、桌面二次批准 | 分享屏幕时不要展示有效二维码 |
| 令牌数据库泄漏 | 服务端只保存访问/刷新令牌哈希；刷新令牌轮换，重放会撤销整台设备 | HTTP 局域网仍会在传输中暴露 bearer token，优先 Tailscale/HTTPS |
| 浏览器管理页泄漏 | 管理口令只换取 HttpOnly、SameSite=Strict Cookie，不写 local/sessionStorage；会话 12 小时；CSP、Host 和 Origin 检查 | 共享电脑应使用独立系统账户，并在离开前撤销管理网页设备 |
| 越权访问桌面 API | 远程默认拒绝；Android 仅可访问显式 allowlist 中的 canonical 创作 API，并且项目级路由必须属于已加入同步的作品；配置、文件系统、更新器、CLI、MCP 和训练接口仍隐藏 | 当前是单用户边界，不适合互不信任的多人共同使用 |
| 离线并发覆盖 | 有序修订号、幂等 mutation、上传优先、冲突保留双方、删除 tombstone | 用户仍需理解并手工选择真正想保留的版本 |
| 恶意或超大输入 | 严格 Pydantic 合同、每批/每实体大小限制、敏感接口限流、TXT 分块 | 文本仍可能包含提示注入；云端写作结果必须审阅 |
| 容器逃逸或供应链 | 非 root UID 10001、`/app` 不可写、最小依赖、amd64/arm64 CI、GHCR 来源标签 | 宿主机与 Docker 运行时漏洞由部署者更新；建议固定版本或 digest |
| 手机丢失 | Android Keystore AES-GCM、系统备份禁用、管理页可撤销设备、断开时服务端撤销 | 已解锁设备上的离线正文仍可能被读取，必须启用系统锁屏和磁盘加密 |
| 手机 API Key 泄漏 | Key 由 Android Keystore 加密保存；手机 API 请求直接发送到作者配置的模型服务，不因 Gateway 已配对而转发，不进入同步实体或日志 | 上游模型服务会接收请求凭据；应使用作者信任的 API 服务 |
| 外部 API 的临时 provider 引入 SSRF | Gateway 的临时 provider 协议继续校验密文、作用域和有效期，并拒绝私网目标；当前 Android 手机 API 不使用该转发协议 | DNS 重绑定和上游代理风险不能完全消除；生产环境还应限制 Gateway 出站网络 |
| 云端模型泄漏 | 显式 Gateway 模型线路与手机独立线路都只发送当前任务选择的项目上下文；Docker 不运行本地 CLI；API Key 不进入同步实体 | 第三方模型的数据政策不受司命控制，不要提交机密内容 |

## 网络部署要求

Android 只允许私有、link-local、loopback、Tailscale 地址使用 HTTP；公共地址必须 HTTPS。可信局域网 HTTP 是兼容选项，不提供传输加密。公网部署必须使用 TLS 终止代理，限制 Host，更新证书并避免在访问日志记录正文、Cookie、Authorization 或请求体。

Gateway 不提供官方账号找回、远程托管备份或多用户权限隔离。需要团队协作、多租户审计或法规合规时，应在另一个明确设计的服务边界中实现，不能把当前 owner/member 角色当作租户隔离。

## 安全验收

- 未登录的远程浏览器只能读取启动器公开状态和管理会话布尔值，其他 API 返回 401/404。
- 错误管理口令不产生会话；Cookie 为 HttpOnly、SameSite=Strict，HTTPS 下同时为 Secure。
- 一次性二维码过期、重复完成、未批准和签名被改写均失败。
- 未显式加入同步的既有作品对 Android 不可见。
- 手机本机操作通过有序修订与命令同步，Gateway 校验真实 ID、归属、版本和生命周期并调用现有领域服务；正文、快照、关联及删除标记应在同一事务捕获。
- 手机模型密文被篡改、绑定到错误设备/作品或超过 5 分钟均失败；请求完成后模型配置不可再读取，失败也不能修改持久化 readiness。
- Android 内置提示词资产必须能由当前 PC `PromptSpec` 和工具 schema 原样重建，源码漂移会使测试失败。
- 刷新令牌重复使用会撤销该设备全部未过期凭据。
- 请求体、限流、Host、Origin、CSP、安全响应头和远程默认拒绝均有自动化测试。
- APK 禁用备份、签名可验证，容器以非 root 运行且只允许 `/data` 写入。
