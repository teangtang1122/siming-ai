# 司命 3.5.0

3.5.0 正式加入 Windows 司命桌宠，让司命在桌面上陪你写作。本版包含 3.4.7 的立项、正文生成、建档、大纲保存和本地模型修复。

## 司命桌宠

- 透明悬浮角色，空白区域可点击穿透，不遮挡底下的应用；修复透明窗口出现黑块的问题。
- 五套独立姿势：抱书站立、读书、贴边探头、坐下打盹、被拎起来；配合眨眼和轻量网格动画，不再依赖旧的分层 Live2D 试验模型。
- 轻点司命会换一句带颜文字的小气泡，约 5 秒后收起；拖动时切换为被拎起的姿势，松手恢复；双击可回到书斋。
- 支持左右贴边探头，探头时缩小原生窗口及点击区域；气泡朝屏幕内侧放置，唤醒或拖动后恢复窗口。
- 显示思考、写作、等待作者确认、完成和错误等任务状态。桌宠只展示状态和提供导航，不代替作者写入、保存或确认作品内容。
- 右键可切换小动作、调节大小与透明度、设置置顶和静音，也可暂时隐藏；默认静音。

## 交互与性能

- 修复调节大小时滑块丢失拖动、菜单跟着移位以及数值回跳的问题。
- 连续缩放只保留最新待处理尺寸，原生请求串行处理；松手后保存最终设置，避免拖动过程中频繁写盘。
- 合并窗口与画布尺寸通知，尺寸实际变化时才调整绘制缓冲区；保留已加载素材，不因缩放反复重建渲染器。
- 角色输入区域按透明轮廓计算，拖动经过头发或袖口空隙时仍能接收松手事件。

## 平台范围与升级

- 桌宠仅适用于 Windows 桌面模式；浏览器模式、Android 和无界面的 Gateway 不创建桌面悬浮窗。Android 与 Gateway 的写作功能不依赖桌宠，也不依赖 PC 界面运行。
- PC、Android、Gateway 版本统一为 3.5.0。升级保留原有作品、模型配置与桌宠偏好，程序文件和作品目录相互独立。
- 发布资源只包含当前姿势渲染路径，不包含旧 Cubism 工程、第三方 Live2D SDK、本机数据或历史测试素材。
- Windows 沿用当前未配置代码签名证书的发布方式，下载后请核对随包 SHA-256；Android 使用既有正式签名，以支持原位升级。

## 验证与下载

- 素材构建检查覆盖 5 套姿势、15 张贴图的哈希、透明格式、眨眼帧与贴边参数。
- 桌宠原生回归覆盖透明合成、点击穿透、气泡寿命、拎起姿势、左右收缩恢复及 9 组连续缩放；发布流程另执行前后端检查、Windows 安装启动冒烟、Android 测试与签名校验，以及发布后资产下载核验。
- Windows：`Siming-Setup.exe` 与 `Siming-Setup.sha256`。
- Android：`Siming.apk` 与 `Siming-apk-sha256.txt`。
- Gateway：`ghcr.io/teangtang1122/siming-ai-gateway:3.5.0`，支持 amd64 和 arm64。

桌宠实现与验证方式见 [桌宠说明](desktop-pet.md)。
