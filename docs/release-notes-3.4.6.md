# 司命 3.4.6

3.4.6 改善手机立项、资料查看和长对话体验，并对齐手机与 PC 的阶段生成请求契约。本次同步发布 Android、Windows 安装包和 Gateway 镜像。

## 立项生成

- 手机阶段生成和结构修复使用流式请求，显示已接收内容的进度；共享 PC 导出的空闲超时、创意输出上限和温度配置。
- 创意结构修复明确完整字段、非空方案数组和保留原方案数量，避免为凑数量复制方案。
- 阶段生成拒绝空内容和工具调用响应，生成结果仍需作者确认；增加阶段、操作和模型请求的调用追踪。
- 手机继续使用本机资料和手机 API 独立生成；资料编辑和确认不需要 PC 或 Gateway 在线。

## 对话与资料

- 输入区固定在对话底部并适配软键盘，阶段导航可直接打开对应资料，显示各阶段确认状态。
- 新回合等待列表布局就绪后滚到最新消息，并提供“回到最新消息”入口。
- 资料卡支持展开完整字段、查看嵌套资料；超过 24 项的列表可继续加载。
- 补充人物身份、关系、世界观、大纲及角色定位等中文标签。

## 验证与发布

- 本地通过 350 项 Android JVM 测试、83 项后端与发布契约测试、28 项手机与 PC 功能契约检查，以及后端架构和导入边界检查。
- Android Debug 和测试 APK 构建、Lint 通过。
- Android 15 模拟器专项回归通过：40 轮长对话与 1.5 倍字体下输入区和最新回复可见，阶段导航不发送模型请求；无 Gateway 或 Gateway 不可达时，资料编辑、确认和重新打开均可在手机完成。
- 正式版本由标签流水线重新构建，执行前后端及 Android 检查、Windows 安装启动冒烟、签名与版本校验、发布后下载核验。

本次模型测试使用合成资料和模拟响应，未进行真实模型 API 或 CLI 的端到端联调。

## 下载

- `Siming-Setup.exe`：Windows 10 x64 或更高版本安装包。
- `Siming-Setup.sha256`：Windows 安装包校验值。
- `Siming.apk`：Android 8.0 或更高版本正式签名安装包，可升级已有正式版。
- `Siming-apk-sha256.txt`：Android 安装包校验值。
- Gateway：`ghcr.io/teangtang1122/siming-ai-gateway:3.4.6`，支持 amd64 和 arm64。
