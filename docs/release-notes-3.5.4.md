# 司命 3.5.4

本版修复模型接入、历史整理与建档中的失败处理，并补齐手机的多 API 和立项多对话能力。PC、Android 与 Gateway 统一版本为 3.5.4，Android `versionCode` 为 `30504`。

## 手机 API 与立项对话

- 支持保存多组加密 API 配置，分别测试、编辑、设为默认，并为任务选择 API 与模型。已有单 API 配置保留并迁入新目录。
- 同一立项支持新建、列出和切换历史对话；消息、运行状态与检查点独立，设定和阶段进度继续共享。新对话不复制整条旧聊天，Agent 通过权威工具读取当前资料。
- 已有单对话历史按幂等迁移保留；任务进行时限制新建和切换，并防止迟到响应写入另一对话。手机独立模式在本机完成，Gateway 使用相同的归属校验和业务契约。

## 历史整理与模型接入

- 分开配置上下文窗口、业务输出和历史整理输出预算，按实际模型最大输出容量约束请求；启用推理时一并计算提供商计入的推理消耗。
- 历史整理截断后，在容量范围内增加输出或缩小完整回合批次；长度恢复与结构、引用修正共用调用上限，不拆分原生工具事务。失败保留原文和有效检查点，暂停后续业务工具，并明确提示“历史整理输出超限”。
- PC 与手机支持按 API、模型保存高级采样和推理参数，共享请求策略。已知不兼容组合明确失败，不静默降低推理档位。
- 修复内部任务编号、存储目标泄漏到外部模型请求顶层导致 OpenAI HTTP 400 的问题；内部追踪和本机 CLI 继续保留编号。参数拒绝保留状态码、参数名和错误码，不公开参数值。
- 区分建连超时与模型响应等待。确认请求尚未送达时最多恢复一次；已发送或送达状态不明的请求不进入这一恢复，避免叠加重试或重放已执行工具。

## 建档与桌宠

- 建档叙事状态在候选提交时校验必需字段，由模型按契约修正，不由应用猜测补写；撤回候选持久化且不再参与正式应用。
- 对正常结束但工具参数不是合法 JSON 对象的响应，整批不执行；保留完整调用与错误回执，交由同一模型有界修正。调用身份不完整或重试耗尽时明确失败。
- 修复 Windows 暗色主题将桌宠透明区域渲染为黑底的问题，主题更新和窗口重建后继续维持透明背景。
