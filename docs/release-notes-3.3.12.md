# 司命 3.3.12

3.3.12 是模型配置兼容与项目助手高可用性补丁。它修复部分从旧版本升级的 DeepSeek 官方配置仍被判断为“缺少可验证容量档案”，并保证项目助手完成资料读取后必须给出可读结论，不能再用“已分析完毕”代替回答。

## DeepSeek 官方配置恢复

- 将司命旧版本曾保存的 `deepseek-v3` 应用别名统一规范为当前官方模型 `deepseek-v4-flash`，模型执行、任务路由、容量目录与上下文档案使用同一身份。
- 新增 `300a34_canonical_model_identity` 数据修订：升级时同步修正全局模型、任务模型、助手会话与容量档案；若作者已经保存当前模型档案，则保留当前档案并移除重复旧别名。
- DeepSeek 官方 HTTPS 端点可直接命中版本化的精确容量档案；主机名末尾带 DNS 点的等价官方地址也可正确识别。
- 自定义代理不会因为使用相同模型名而被误认为官方部署，仍需按实际服务文档配置上下文容量。
- Windows、Gateway 与 Android 手机直连使用相同的旧别名兼容规则；Android 会在请求前发送规范化后的当前模型 ID。

## 项目助手最终答复恢复

- 删除旧版达到固定轮次后返回“已分析完毕”的占位答复。
- 取消项目助手固定的工具往返轮次上限；只要模型仍在合法调用工具，就继续执行，直到模型给出最终答复、作者取消、终止型草稿生成或发生真实错误。
- 当模型只返回思考内容、未返回正文时，自动进入无工具补偿；若第一次仍为空，会再安全重试一次。
- 最终总结明确要求给出结论、依据和仍缺少的信息，不能只声称已分析、已完成或要求作者等待。
- 补偿阶段不会重新开放或重放业务工具，因此读取不会重复，写入也不会因重试再次执行。
- 两次补偿仍无正文时，本轮保持真实错误状态并保留工具回执供安全重试，不会把空回复标记为完成。
- Android 独立项目助手同步采用相同的无工具总结与空回复重试策略；DeepSeek 最终总结会关闭思考模式，把输出预算留给可见正文。

## 兼容升级

安装后首次启动会按现有流程备份并升级数据库。该修订只规范模型配置身份，不修改作品正文、正式章节、草稿、角色或世界观数据。升级后仍可继续使用已保存的 DeepSeek API Key，无需重新输入。

## 下载

正式 Release 提供：

- `Siming-Setup.exe`：Windows 10 x64 或更高版本安装包
- `Siming-Setup.sha256`：Windows 安装包 SHA-256
- `Siming.apk`：Android 8.0 或更高版本正式签名安装包
- `Siming-apk-sha256.txt`：Android APK SHA-256

Windows 项目当前尚未配置 Authenticode 证书时，请在安装前同时核对 Release 提供的 SHA-256；Android APK 使用正式发布密钥签名。
