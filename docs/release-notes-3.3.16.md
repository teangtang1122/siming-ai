# 司命 3.3.16

3.3.16 修复立项过程中实体改名后引用失效、工具错误缺少细节，以及 DeepSeek 等模型把工具协议输出到最终回复的问题；Android 独立模式同步相关修复。

## 立项资料引用与错误反馈

- 通过实体编辑工具按 ID 修改名称时，保留原实体 ID，后续生成可以继续引用同一条资料。
- 引用已删除或其他会话的实体、目标对象不匹配、实体类型错误时，在生成前明确拒绝，并向模型返回安全的错误代码、字段位置和修正说明。
- 工具契约明确列出实体类型，区分 `characters` 阶段与 `character` 实体，帮助模型修正参数。
- 实体身份冲突会原子拒绝；删除实体不会错误绑定后续条目。既有已删除 ID 不会自动恢复，Agent 需重新读取当前有效实体。

## 立项回复收尾

- 工具阶段结束后进入明确的总结步骤，说明本轮真实执行结果。
- DSML、未授权工具调用和空回复不能作为最终回复显示；总结不合格时只纠正总结，不重放已经完成的读取或写入。
- 总结仍失败时保留已完成的修改，并展示可验证的回执。已启动任务与已完成生成分别报告。

## 手机端

Android 独立模式同步最终回复校验、实体引用与类型预检，并将明确选取的实体上下文交给生成步骤。共享类型、错误说明和回复协议通过同一契约导出，手机执行不依赖 PC 客户端运行。

## 诊断与验证

源码增加独立的 Phoenix/OpenTelemetry 本地诊断脚本，用于查看已有立项记录及开发测试后端的实际 API 交互。历史记录明确标注缺失内容；工具保存在开发目录，不进入本次产品安装包。本版本尚未内置上下文查看页面或新增压缩策略。

相关 203 项后端与诊断测试、39 项 Android 立项测试、Android lint、后端质量检查及 27 项手机/PC 能力契约校验已通过。测试使用模拟接口和测试数据库。正式附件由标签发布流水线构建，并执行完整发布检查、安装冒烟及发布后下载校验。

## 下载

- `Siming-Setup.exe`：Windows 10 x64 或更高版本安装包。
- `Siming-Setup.sha256`：Windows 安装包校验值。
- `Siming.apk`：Android 8.0 或更高版本正式签名安装包。
- `Siming-apk-sha256.txt`：Android 安装包校验值。

正式 APK 使用现有发布证书，应用 ID 为 `com.siming.mobile`。此前的 `com.siming.mobile.debug` 测试版使用独立数据空间。
