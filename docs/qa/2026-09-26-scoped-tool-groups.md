# 立项与项目工具分组验证

## 本次变更

- 同一权威目录中的每类工具缩小到 2～6 个。
- PC 立项的 32 个工具分为 10 类，每类 2～5 个；类别菜单只包含当前立项入口可执行的工具。CLI 隐去会递归启动模型的生成工具，手机继续按其已有独立实现提供子集。
- 项目助手排除立项工具；正文草稿独立为 `chapter_writing`，上下文检索、章节查询、大纲、人物等分别开放。
- 自由对话每步最多选择两类，替换而非累加；API、临时 MCP 和手机端同时校验范围与数量。跨范围的类别选择不会改变状态或执行工具。
- 固定建档直接获得任务工具：原生 API 和手机 4 个，托管 CLI 9 个（含进度上报、验证）。去掉建档的类别选择及重启循环，保留持久候选、校验、事务、取消与重试。
- 章节评分和去 AI 味保留原有独立模型调用，CLI 隔离执行，不进入通用类别选择流程。
- PC 和手机立项界面明确提示：仅筹备资料，章节正文在创建正式作品后由项目助手生成。
