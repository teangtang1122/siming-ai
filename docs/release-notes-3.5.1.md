# 司命 3.5.1

本版简化首次模型配置，调整手机创作界面，并修复 Windows 覆盖安装与 OpenCode 模型发现中的问题。

## 快速开始与模型接入

- 快速开始只提供 API 接入：从官网获取 API Key，填写模型配置，完成真实对话测试后开始创作。
- 提供 DeepSeek、通义千问、OpenAI、Anthropic Claude、Google Gemini 的官网密钥入口，也支持自定义 OpenAI 兼容 API。
- 已有可用模型时直接进入故事输入；本地模型和已有 CLI 继续从模型中心、模型设置接入。
- 移除 OpenCode 免费模型自动安装、轮试与后台恢复流程。升级时停止旧准备任务，保留历史记录、模型配置和作品数据。
- OpenCode 显式重新检测使用 CLI 返回的最新目录，不再依赖过时的内置名单；普通调用和建档均保留作者选择的模型 ID，不静默替换。免费标签不保证第三方 Agent 可用，模型权限与额度以服务方及连接测试结果为准。

## 手机创作界面

- 书架支持搜索，新建入口集中提供 AI 立项、空白作品和导入操作。
- 书内使用“写作 / 大纲 / 助手 / 资料”导航，常用写作操作集中在首屏。
- 立项对话与资料目录分开，资料默认使用中文字段编辑；原始 JSON 放入高级入口。
- 键盘弹出时调整可用空间，返回与切换页面保留未提交输入；尊重系统字号设置。
- 手机直连 API 仍独立运行；仅在作者主动选择 Gateway 模型或同步时使用远端能力。

## Windows 安装与退出

- 关闭主窗口时同时关闭桌宠，减少隐藏进程持续占用运行库的情况。
- 安装器在清理旧运行库前检查文件能否替换。若文件被占用或无写入权限，停止安装并保留旧程序，提示退出相关进程后重试。
- 默认保存安装日志，便于定位“拒绝访问”等安装错误。覆盖安装保留独立存放的小说资料与模型配置。

## 验证范围

- 发布流程执行前后端检查、Windows 安装启动冒烟、Android 单元测试与 lint、正式 APK 签名校验和发布资产核验。
- 快速开始回归覆盖 API 官网入口、真实模型就绪状态、失败重试和手动创作入口；安装器回归覆盖运行库被占用时保留原文件、解除占用后升级及全新安装。
- 本地 Qwen3.8 27B Q3 此前已在 **64K 上下文**配置下成功跑通立项、写作和建档等完整流程；本次发布不据此承诺所有模型、所有请求均成功。详情见 [本地模型说明](https://github.com/teangtang1122/siming-ai/blob/v3.5.1/README.md#本地模型)。

## 下载与升级

- Windows：`Siming-Setup.exe`、`Siming-Setup.sha256`。
- Android：`Siming.apk`、`Siming-apk-sha256.txt`，沿用正式签名，支持覆盖升级。
- Gateway：`ghcr.io/teangtang1122/siming-ai-gateway:3.5.1`，支持 amd64 与 arm64。

Windows 安装前请保存工作并退出司命和使用同一安装目录的 MCP 进程；若安装被文件占用检查阻止，退出相关进程后重试。Windows 安装包沿用未配置代码签名证书的分发方式，可用随包 SHA-256 校验完整性。
