# 司命 3.4.3

3.4.3 修复手机独立模式下“保存并建档”被禁用的问题。手机配置 API 后，可以在本机完成章节建档，不再需要连接 Gateway。本次同时更新 Android 和 PC/Gateway 的建档同步接收逻辑。

## 手机独立建档

- 在 AI 章节草稿页点击“保存并建档”，先保存作者确认的正文，再使用手机配置的 API 建档。已经保存但尚未建档的章节，也可以在作品工具页启动建档。
- 按完整正文和现有资料形成建档计划，更新章节摘要、角色基础信息、剧情状态、写作约束与版本、世界观、大纲层级及角色关联、伏笔和治理资料。手机与 PC 使用同源工具契约和共享测试样例。
- 建档计划通过完整性和实体归属检查后整章提交；失败保留正文、候选计划和错误，支持取消、查看记录及明确重试。运行期间正文或相关资料发生变化时拒绝写入，避免覆盖作者的新修改。
- AI 生成章节草稿后仍结束当前回合，由作者决定保存、建档和何时继续下一章。建档完成后才能通过下一章的续写检查。

## 导出与同步

- 完整项目包导出、导入及再次导出时保留章节、大纲与角色、世界观的关联，项目包 v1 格式保持不变。
- 手机建档结果随后同步到 PC 时，按正文保存、建档、后续编辑的顺序处理；PC 校验原文版本及相关资料后使用正式建档流程接收，不会再次调用模型生成计划。
- 重复同步不会重复增加资料版本或历史记录；同步中断保留待确认记录，后续作者编辑不因较早的同步回执而丢失。
- Android 数据库升级保留既有作品，并修复有完整快照依据的旧版待同步正文版本。

**升级提示：手机独立建档只需更新 Android 并配置可用 API；若需把建档结果同步到电脑，请同时升级 PC/Gateway 至 3.4.3 或更高版本。** 手机端提供建档记录、取消和重试；逐条编辑候选计划的管理界面仍在 PC/Gateway，移动端差异已记录在 [能力对齐说明](https://github.com/teangtang1122/siming-ai/blob/v3.4.3/docs/mobile-pc-parity.md)。

## 测试范围

- 本地通过 344 项 Android JVM 测试、6 项 Android API 35 模拟器测试和 112 项后端回归。
- 模拟器覆盖无 Gateway 建档、解除续写门槛、网络失败重试、取消与中断恢复、正文并发修改保护、数据库升级，以及连续保存和建档结果的有序同步。
- 共享合成作品验证手机和 PC 的角色资料、状态、写作约束、版本、大纲绑定及治理结果；没有使用真实用户作品作为公开测试数据。
- 提示词资产漂移、移动端能力契约、架构检查及 Android 测试构建通过。正式安装包由版本标签流水线重新构建，执行前后端、Android、Windows 安装冒烟及发布后下载校验。

**既有 AI 实际运行问题分析与测试主要基于 DeepSeek API 的 `deepseek-flash`。本次手机独立建档回归使用模拟的模型工具调用和网络故障，尚未完成真实 DeepSeek 端到端验收。使用其他模型或 CLI 可能存在未知 bug，尚未完成同等范围的实机验证。**

## 下载

- `Siming-Setup.exe`：Windows 10 x64 或更高版本安装包。
- `Siming-Setup.sha256`：Windows 安装包校验值。
- `Siming.apk`：Android 8.0 或更高版本正式签名安装包，可升级已有正式版。“司命（测试版）”使用独立应用标识，资料不会自动合并到正式版。
- `Siming-apk-sha256.txt`：Android 安装包校验值。
