# 司命 3.3.0

3.3.0 是一次跨端创作体验升级：重点补齐 OpenCode MCP 快速配置与建档稳定性，并对 Android 手机端进行了四阶段 UI/工作流重构，使手机端从“PC 功能缩小版”进一步变成可独立使用的小说创作客户端。

## 主要更新

### OpenCode 快速开始与 MCP 建档

- 快速开始在 OpenCode 模型准备完成后新增 Siming MCP 配置与验证步骤，不再出现“模型能用但建档工具未接入”的隐性缺口。
- 建档前增加 MCP preflight，区分未配置、未连接、权限阻塞、模型未调用工具等失败原因。
- OpenCode 建档子进程仅开放作品读取与建档所需的 Siming MCP 工具，不额外开放通用写文件或 shell 权限。
- 修复 Cataloging 将权限请求、MCP 未加载等情况统一误报为“CLI 未保存”的问题，并保留直连 JSONL 兜底。
- 司命自己下载、未加入 PATH 的 OpenCode 也可被快速开始正确配置。

### Android 作品管理与导入导出

- 手机作品库支持删除作品；已同步作品离线时会阻止不安全的本地硬删，避免下次同步复活。
- 大纲支持卷 → 章 → 节树形展开、同级排序和结构化浏览。
- TXT 导入完成后可直接进入作品建档流程；连接 Gateway 时复用 PC 正式 Cataloging。
- 手机支持小说导出：连接 PC 时可导出 TXT / DOCX / PDF，离线或独立模式可直接导出 UTF-8 TXT。
- 导出使用 Android 系统文件保存界面，不要求额外的全盘存储权限。

### 手机正文与资料工作区重构

- 作品库成为默认首页，作品内主导航重组为“正文 / AI / 资料 / 工具”。
- 正文章节从通用资料表单中拆出，新增章节目录、沉浸式阅读态、专用编辑态和手机化章节操作。
- 角色与世界观改为独立目录、阅读详情和编辑工作区；后台 revision、sort_order、JSON 等技术字段默认隐藏。
- 角色稳定写作锁、世界观 canonical 顺序等高级字段继续保留，但仅在需要时展开编辑。

### AI 共创与叙事资料重构

- AI 共创改成消息流体验，支持用户/司命消息气泡、快捷意图、底部输入器、范围切换和模型线路切换。
- 伏笔与叙事承诺改为专用追踪工作区，突出生命周期状态、优先级、目标章节和回收计划。
- 低频的章节 ID、因果 ID、证据和复检字段收进高级追踪区，不再干扰日常创作。

### 大纲、同步与设置体验

- 大纲父级改为作者可读选择，不再要求手输 `parent_id`；`sort_order` 默认隐藏。
- 新建或更换父级的大纲节点自动追加到同级末尾，避免默认 `sort_order=0` 跑到最前面。
- 手机端会阻止直接删除仍有子节点的卷/章，避免 PC 数据库级联删除整棵子树。
- 同步页改为“同步健康状态 → 立即同步 → 版本分岔 → 连接详情”的任务流；原始 JSON 快照、Gateway URL 与指纹默认收起。
- 设置页按 AI 模型、跨设备、数据与隐私、关于重新分组，技术配置降到二级操作。

## 跨端与数据安全

- Android 继续复用 PC canonical 数据契约、可靠 outbox、冲突保护和 Gateway API，没有建立第二套手机端权威数据模型。
- 手机 UI 隐藏的 canonical 字段仍通过 `basePayload` 原样保留，编辑不会因界面简化而丢失高级数据。
- mobile / PC parity contract 与 Architecture CI 持续覆盖关键写作、建档、导出、同步和治理能力。

## 下载

正式 Release 提供：

- `Siming-Setup.exe`：Windows 安装包
- `Siming-Setup.sha256`：Windows 安装包 SHA-256
- `Siming.apk`：Android 安装包
- `Siming-apk-sha256.txt`：Android APK SHA-256

Windows 正式发布继续使用安装包形式，不提供旧版单文件 `Siming.exe`。
